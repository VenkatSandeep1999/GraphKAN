# GraphKAN
This is a deep learning model to predict vehicle energy consumption in various road segments of a city
Get started
Install dependencies pip install -r requirements.txt

Change config_fig.yaml's data_path and model_path variables accordingly to reflect correct PC path

Check model_name in config_fig.yaml for the model to run. And also change use_lookup and ablate_vehicle etc.. parameters according to the model.

Run python train.py

Run python train_pytorch.py to run GraphKAN.
